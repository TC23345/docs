The harness has four pieces. Each does one job.

## Skills (`.claude/skills/`)

Knowledge-and-procedure capabilities the agent auto-discovers based on your intent. You don't invoke them by name — you say what you want and Claude pulls in the matching skill. Each skill has a `SKILL.md`; some have `assets/` (templates) and `references/` (long-form references).

Trigger phrases: "let's brainstorm business names" → `business-name`. "I want to set up the IL entity" → `entity-setup`. "Draft the fee schedule" → `services-fees`. "Build the intake form" → `intake-process`.

See [Skills](/harness/skills) for the live list.

## Commands (`.claude/commands/`)

Rylee-initiated rituals with predictable behavior. Type `/name` in Claude Code.

| Command | What it does |
| --- | --- |
| `/session-start` | Read `workspace/progress.md`, surface where you left off |
| `/progress` | Render and update the course progress dashboard |
| `/new-client <name>` | Instantiate a client folder from `intake-process` assets |
| `/find <query>` | Grep `workspace/` for a string |

See [Commands](/harness/commands).

## Workspace (`workspace/`)

The committed practice ledger. Every file carries frontmatter (`client_id`, `created`, `last_updated`, `module_context`). `workspace/clients/` uses `<lastname-firstinitial>-<yyyymm>/` per-client folders. Session logs are append-only, dated.

## Course companion (this site)

Browsable Mintlify site for module summaries, glossary, and IL resources. Workspace is intentionally not published here — the site is read-only reference, the workspace is your private practice ledger.

## Conventions worth knowing

- **Description drift.** When the brother edits a `SKILL.md` procedure, the `description` frontmatter must be re-justified. Stale descriptions break auto-discovery.
- **PII naming.** Client folders use `<lastname-firstinitial>-<yyyymm>/`. Never paste full client names or unabbreviated district names in commits.
- **Append-only logs.** New session = new dated block in `session-log.md`. New observation = new dated file in `observations/`.
- **Scope-of-practice gate.** Skills defer entity tax, binding contracts, insurance selection, and child-specific legal strategy to licensed professionals. See `.claude/shared/disclaimer.md`.
