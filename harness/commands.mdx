## `/session-start`

Reads `workspace/progress.md`, identifies the current module and next blocked decision, and offers a resume point. Run at the top of every working session.

## `/progress`

Renders the current state of `workspace/progress.md` as a checklist (modules, deliverables, blocking decisions). With no arguments: read-only render. With arguments (`/progress checked module-1.business-name`): update a row.

## `/new-client <name>`

Instantiates a client folder under `workspace/clients/`. Name is parsed into the canonical `<lastname-firstinitial>-<yyyymm>` id. Copies templates from `.claude/skills/intake-process/assets/` and populates frontmatter. Prompts for the few values that must be filled at intake time (referral source, presenting concern in two words, state of IEP).

Example: `/new-client Doe-Jamie` → creates `workspace/clients/doe-j-202605/` with `intake.md`, `iep-checklist.md`, `session-log.md`, `observations/` (empty).

## `/find <query>`

Greps `workspace/` for the query string. Returns matched files with one-line context. Frontmatter fields (`client_id`, `module_context`) are searchable.
