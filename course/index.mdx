## Relevance legend

- **High** — new content for Rylee, or business operations she has not done before
- **Medium** — partial overlap with her current role; some new framing
- **Low** — review only; she already operates fluently in this material

## Build tiers

The harness ships skills and commands incrementally so each tool reflects real practice rather than guesses.

- **Tier 0** — orientation: `CLAUDE.md`, disclaimers, this site's structure. Done.
- **Tier 1** — Module 1 + cross-cutting commands (`/session-start`, `/progress`, `/new-client`, `/find`). Done.
- **Tier 2** — Modules 2 and 3 thin slice + first real client folder. Scaffold when Rylee is partway through Module 1.
- **Tier 3** — Modules 4–8. Scaffold as she enters each module; intake experience will reshape these skills.
