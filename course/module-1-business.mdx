The course's promise for Module 1: take "research private practice insurance and licensing" off the to-do list. Five deliverables.

## Deliverables

1. **Business name + state entity** — pick a name, check IL Secretary of State availability, register the entity.
2. **Liability insurance updated** — extend professional liability coverage to the new private practice.
3. **Services + fee structure** — define exactly what services Rylee offers and the fee for each.
4. **Back-end systems** — file organization, document storage, contract scaffolding.
5. **Client intake process** — repeatable intake from first contact through signed engagement.

## Working order Rylee usually wants

1. Brainstorm names → land on top 3 → check IL availability
2. Pick entity type (LLC vs PLLC for a BCBA in IL — defer the tax-classification question to a CPA)
3. File with IL SoS + get EIN
4. Talk to insurance broker (the harness can prep questions but does not select coverage)
5. Draft services catalog and fee schedule
6. Draft intake form, welcome packet, services-agreement checklist (for attorney review)
7. Dry-run the intake with a fake client via `/new-client Test-Family`
