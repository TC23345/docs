# Shirley Road IEP Advocacy Docs

Public Mintlify resource site for Shirley Road IEP Advocacy.

This repo is the parent-facing education and services surface. Internal course operations and private working notes live in the separate `rylee-iep` app.

## Local preview

```bash
npm i -g mint
mint dev
```

Open `http://localhost:3000`.

## Content boundary

Do not add client records, private practice notes, course tracking material, command automation, or internal Rylee/Taylor operating notes to this public site. Draft service and guide copy should be reviewed by Rylee before launch.
